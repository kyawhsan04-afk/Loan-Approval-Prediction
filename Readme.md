Prediction of Approval of Bank Loans

An online application that utilizes machine learning algorithms to determine whether or not a bank loan is likely to be approved based on the data available about the borrower.

Machine Learning Methods

This project utilizes a Support Vector Machine (SVM) model for classification that uses a linear kernel.

Input Features

The model takes into account the following features of the loan applicant:

- Gender
- Marriage status
- Number of dependents
- Educational background
- Employment status
- Current income
- Coapplicant’s income
- Loan amount
- Duration of the loan
- Credit history
- Area of property

Technologies employed in the project

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
